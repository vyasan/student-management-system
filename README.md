# Student Management System

A complete Student Management System built with Python
as the capstone project for Phase 1 of the
Advanced AI & ML Training Program at Edvuber.

## Features
- Add, search, update, and delete student records
- Automatic grade and result calculation
- Attendance tracking with status alerts
- Scholarship eligibility detection
- CSV persistence with auto-backup
- Full class analytics and statistics
- Export formatted report cards to text file

## Technologies Used
- Python 3.x
- OOP — Classes and Inheritance
- CSV module for data persistence
- Exception Handling throughout
- datetime, os, shutil standard modules
- String handling and validation

## How to Run
python student_management_system.py

## Concepts Demonstrated
Variables, Data Types, Operators, Conditions,
Loops, Functions, Collections, String Handling,
File Handling, Exception Handling, OOP
